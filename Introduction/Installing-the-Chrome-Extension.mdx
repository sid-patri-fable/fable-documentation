There are two ways you can create a demo using Fable:

- **Using Fable’s Chrome Extension (Recommended)**: This is the only way to create fully interactive HTML demos which are auto-stitched by Fable. Please head over to [Fable’s Chrome Extension](https://chromewebstore.google.com/detail/fable-create-step-by-step/ekmabenadlgfkjplmpldkjkhiikobaoc?pli=1) page and install the extension.
- **Individually Uploading Screenshots**: In case you want to create a simple screenshot capture demo, you can individually upload images and stitch them together manually to create an interactive screenshot demo.

We highly recommend using the Chrome extension to create the demo as it will be auto-stitched, create fully interactive demos and overall lead to a better output.
