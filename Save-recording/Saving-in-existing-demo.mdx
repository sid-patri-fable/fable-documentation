# Saving to an Existing Demo

Fable makes it easy to build on your existing demos by allowing you to save new recordings directly into them. This feature enables you to incrementally add more screens and content, expanding your demo without needing to start from scratch. Whether you're updating a project or adding new information, this flexibility ensures your demos stay up-to-date and comprehensive.

The demo below walks you through how to save new recordings into an existing demo, showcasing the ease and efficiency of this process in Fable’s platform.
