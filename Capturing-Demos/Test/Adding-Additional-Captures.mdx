# Adding Additional Captures to an Existing Demo

In cases where you want to add additional captures to an existing demo, you can easily achieve that by selecting the ‘Save in an existing demo’ option after capturing the steps.

As before, you can go to your web page/application and capture the additional steps that you want to add to an existing demo by firing up the extension. Once the capture process is done, at the time of selecting where you want these captures to be added, select ‘Save in an existing demo’ option. The interactive demo below will guide you through the steps.
