### Resetting the Extension State

If you encounter issues where Fable’s Browser Extension becomes unresponsive or freezes, a simple reset can quickly resolve the problem. Resetting the extension state can refresh its functionality without the need for more complicated troubleshooting steps.

To reset the extension, just follow this straightforward process: click the gray square button located in the top-right corner of the extension's popup window. This action will instantly reset the browser extension's state, allowing it to resume normal operation.

Whether you're mid-demo or making critical adjustments, this quick reset ensures you can continue using the extension smoothly without significant interruptions. Check the image below for reference on where to find the reset button:
