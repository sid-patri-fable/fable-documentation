# Overview of Advanced Annotation Creator Panel Options

The Advanced Options in Fable's Annotation Creator panel offer a range of powerful customization features that allow you to fine-tune the behavior and appearance of your interactive demos. These options provide greater control over how your annotations are presented and how users interact with them. Here's a breakdown of the key features available in the Advanced Options panel:

1. **Entry Point**: This option allows you to select which annotation the demo will start with. The entry point is visually marked by an arrow above the designated annotation card. Setting the right entry point helps guide your audience through the demo in a logical flow.

2. **Overlay**: This visual feature allows you to toggle whether a transparent black overlay is displayed behind the annotation card. Enabling this option helps to draw attention to the annotation by subtly dimming the background, creating a more focused experience for the viewer.

3. **Scroll Adjustment**: This setting allows you to control how the annotated element is scrolled into view during the demo. You can select from the following three options in the dropdown:
   - **Auto**: Fable automatically decides whether to scroll the element into the center based on screen space and other factors.
   - **Scroll**: Fable will force the annotated element to scroll into the center of the screen, ensuring it's fully visible.
   - **Sticky**: Fable will not scroll the element into view, allowing the annotation to remain in its current position on the page.

   While you can customize this setting based on your needs, it’s often best to leave it set to **Auto** for an optimal experience.

4. **Show Step Progress**: This toggle option lets you decide whether to display a progress bar at the top of your demo, indicating the user's progress through the steps. This feature can improve user engagement by providing a clear visual cue of how far they’ve come and how much remains in the demo.

5. **Reduce Motion on Mobile**: This option is designed to optimize the demo experience for mobile users, particularly on low-powered devices. When enabled, Fable will reduce motion effects, ensuring smoother performance for viewers primarily accessing your demo on mobile. If your target audience is likely to use mobile devices, this is a valuable feature to enhance usability.

These advanced options provide flexibility and customization, allowing you to tailor your interactive demos for the best possible user experience. Whether it's choosing where the demo starts, adjusting how elements scroll into view, or optimizing for mobile, Fable gives you the tools to create refined, engaging annotations.
