# Toggle Annotation Overlay

The annotation overlay feature provides a visual enhancement by allowing you to enable or disable a transparent black overlay behind the annotation card. When activated, this overlay subtly dims the background elements, drawing attention directly to the annotation. This creates a more immersive and focused experience for the viewer, ensuring that the key information presented in the annotation stands out clearly without distractions from surrounding content.

Using the overlay is especially helpful when highlighting important steps or features in your demo, as it increases the emphasis on the annotation while maintaining a polished, professional look.

The Fable demo below demonstrates how to easily toggle the annotation overlay feature, helping you create a more engaging and visually appealing user experience.
