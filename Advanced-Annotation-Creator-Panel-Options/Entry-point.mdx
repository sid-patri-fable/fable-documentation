# Entry Point

Entry point means the annotation at which the demo would start. You can mark an annotation as the entry point by opening it and ticking the entry point option in the advanced settings in the creator panel. If an annotation is set as the entry point, then it will be denoted by a curved arrow abve the annotation card in the canvas.
