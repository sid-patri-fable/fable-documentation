# Creating a New Demo Hub

Creating a new Demo Hub in Fable is quick and easy. When you start, Fable provides a pre-built template that includes essential elements like preconfigured CTAs and sections, giving you a head start on customization. You can easily edit, rearrange, or delete these sections to match the specific demos and features you want to highlight.

This flexibility allows you to craft a Demo Hub that perfectly showcases your product's capabilities. To see how simple it is to set up, check out the Fable demo below, which guides you through the process step-by-step.
