# Single Select Qualification

The Single Select Qualification is a widely used and fundamental feature within Demo Hub, designed to personalize the user experience by presenting tailored demos based on user preferences. In this type of qualification, users are given a set of options and are asked to select the one that best matches their interests. Based on the option they choose, the Demo Hub dynamically displays relevant demos that align with their selection.

For instance, if your application has various sections, such as in the case of Fable, where the app includes areas like editing demos, adding integrations, and creating demo hubs, you can create a Single Select Qualification to guide users to the content they care about most. You could title the qualification "What part of Fable are you interested in?" and provide three options: 
- A. Demo Editing
- B. Adding Integrations
- C. Demo Hubs

When a user selects one of these options and proceeds, the Demo Hub will automatically display the demos associated with their chosen area of interest. This method not only streamlines the user journey but also ensures that each prospect is presented with content that is most relevant to their needs, enhancing their experience and increasing engagement.

By implementing thoughtful and personalized qualifications like Single Select, you can effectively cater to the unique needs of each prospect, making your Demo Hub a powerful tool for targeted and impactful presentations.
