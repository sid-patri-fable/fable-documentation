Guide is the information that guides a viewer through the interactive demo. In Fable, there are three types of guides and two formats for guide messages - text and video.

## Types of Guides

In Fable, there are 3 types of guides:

<img width="330" alt="..." src="https://documentden-deployments.s3.us-east-1.amazonaws.com/public/3a190da8-faf9-4c76-9acb-a1689691e2b7"></img>

- **Element Guide**: An element guide is a guide message that is associated with an element of the screen (e.g. an element guide that highlights a button and asks a viewer to click on the button to proceed).
- **Cover Guide**: A cover guide is a guide message that is not associated with an element of the screen but the entire screen itself (e.g. a start/end message in an interactive demo which gives an overview/summary of the demo).
- **Multi Guide**: A multi guide is a guide message that creates a branch from the main demo. This can be used to create branched demos where you can give a viewer different paths to follow in the demo.

## Guide Message Formats

There are two formats of guide messages in Fable:

- **Text Guide Message**: The guide message is in the form of text.
- **Video Guide Message**: The guide message is in the form of video.
