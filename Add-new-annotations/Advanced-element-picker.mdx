### Advanced Element Picker in Fable

Fable's **Advanced Element Picker** offers enhanced control when selecting elements for annotations, making it easy to highlight not only specific elements but also their parent containers. This feature is especially useful in complex interfaces where elements are nested within multiple layers.

For example, if you want to annotate a button that is part of a group of buttons contained within several parent divs, the Advanced Element Picker allows you to select not just the button, but also the parent containers that house it. This capability is ideal for situations where you need to draw attention to broader sections of your app, such as entire groups of buttons or larger UI components, rather than a single element.

Here’s why the Advanced Element Picker is so powerful:

1. **Granular Selection Control**: You can navigate the hierarchical structure of your app’s interface to select parent elements, making it easier to annotate entire sections without having to create multiple individual annotations.

2. **Highlighting Contextual Areas**: By selecting parent containers, you can provide more context to your users. This is helpful when showing how individual elements relate to the broader structure of your app, giving users a clearer understanding of the UI layout.

3. **Efficient Annotation**: Instead of creating separate annotations for each element, the Advanced Element Picker lets you quickly select and annotate larger components, streamlining the demo creation process.
