# Annotation size

Fable provides you with options to change the size of the annotation. You can select from preset sizes such as small, medium, and large.  Apart from these preset sizes, you can also opt to go for custom sizes, in which you can give a value in pixels. This feature is useful when you want to change the annotation size so that the annotation content fits in the most optimum way inside the card.
