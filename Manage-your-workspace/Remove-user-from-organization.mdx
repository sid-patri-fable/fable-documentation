# Removing a User from an Organization

Removing a user from an organization in Fable is straightforward.

The demo below shows how to remove a user from an organization in Fable.

<FableEmbed src="https://app.sharefable.com/embed/demo/removing-user-from-wor-6ae0i0ry1k5at4lb" />

## Step-by-Step Guide

### Step 1
Go to the User Management section in the sidebar.

<img alt="..." src="https://documentden-deployments.s3.us-east-1.amazonaws.com/public/6390507c-dfc5-4db6-bf9f-85fe25feb3fd"></img>

### Step 2
Select the user you want to remove and click the icon on the right side of their user card.

<img alt="..." src="https://documentden-deployments.s3.us-east-1.amazonaws.com/public/9f0558c3-4e05-4e27-adce-5a6d9ef695b4"></img>

And just like that, the user is removed!
