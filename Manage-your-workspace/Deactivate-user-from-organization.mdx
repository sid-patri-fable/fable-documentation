# Deactivating a User from an Organization

Deactivating a user from an organization in Fable is straightforward. You would want to deactivate a user from your organization to manage the total seats which are part of your subscription plan. For e.g., the current Startup plan costs $50/creater/month. Hence, if 2 users are part of your organization, you will be billed 2 * 50 = $100 a month. Therefore, deactivating a user, removes his/her from occupying a seat in your billing cycle.

Disclaimer: If a deactivated user signs into Fable, their account gets activated again.

The demo below shows how to deactivate a user from an organization in Fable.

## Step-by-Step Guide

### Step 1
Go to the User Management section in the sidebar.

### Step 2
Select the user you want to deactivate and click the icon on the right side of their user card.

<img alt="..." src="https://documentden-deployments.s3.us-east-1.amazonaws.com/public/9f0558c3-4e05-4e27-adce-5a6d9ef695b4"></img>

And just like that, the user is deactivated!
