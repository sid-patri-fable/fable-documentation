# Understanding and Adding Segments in a Module

A segment within a module represents a specific flow in your interactive demo. For example, if you've created distinct flows for each feature in your app, each flow would be considered a segment. Think of segments as the individual chapters of a book, each guiding the user through a different part of your demo.

Adding segments to a module is a straightforward process in the Fable Canvas Editor. Each segment can be customized with a title and a description, providing context and clarity to your users. Additionally, you have the flexibility to designate segments as mandatory or keep them optional by default, depending on the needs of your demo.
