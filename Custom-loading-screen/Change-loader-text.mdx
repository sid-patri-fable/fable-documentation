# Customizing Loader Text

Fable makes it easy to customize the text displayed on the loader screen before your demo starts. This feature allows you to set the tone and provide a personalized message to your audience while they wait for the demo to load.

In the following Fable demo, you'll see how to change the loader text to fit your needs and enhance the user experience.
