# Overview

With Fable's integration for Zapier, connect to 6000+ apps to sync your demo analytics and lead details to your marketing and sales stack.

# How to connect to Zapier

Fable connects with Zapier via API key. Following steps will guide you to do the setup

1. Go to [app.sharefable.com](https://app.sharefable.com) and login
2. Genreate an API key from [settings](https://app.sharefable.com/settings) tab. If you already have an API key, you can simply click on the key to copy the key.
3. Head to [zapier](https://zapier.com/app/zaps) and create a new zap
4. Select Fable app and and event to start the automation
5. Zapier would prompt a screen where you can paste the API key that you have copied in step 2
6. Once your account is connected select the demos for which you'd want to run the zap for
7. Choose from 6000+ apps to build your automation

That's it.

# How to test the integration

1. Create a demo
2. Add a lead form to the demo
3. Publish the demo
4. Open the published link in a tab
5. Fill up the lead form
6. You should see your zap getting triggered within 2 mins
