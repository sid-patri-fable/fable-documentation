# Overview

With Fable's integration for Slack, get notified in realtime whenever your buyers interact with a demo. This integration also unfurls demo URL in Slack and provides contextual action buttons with the unfuled content.

# How to connect to Slack

Install Fable's Slack bot by clicking the following button

<a href="https://slack.com/oauth/v2/authorize?client_id=3799129270130.7037987086070&scope=channels:history,channels:read,chat:write,groups:read,links:read,users:read,links:write&user_scope=users:read,channels:read,groups:read,chat:write,channels:history"><img alt="Add to Slack" height="40" width="139" src="https://platform.slack-edge.com/img/add_to_slack.png" srcSet="https://platform.slack-edge.com/img/add_to_slack.png 1x, https://platform.slack-edge.com/img/add_to_slack@2x.png 2x" /></a>

Perform the following steps to configure how Fable should send notification in Slack

1. Go to Slack and create a channel where Fable would send notification to
2. Go to [app.sharefable.com](https://app.sharefable.com) and login
3. Go to *Integrations* tab from the side panel
4. Click on Slack from the list of integrations
5. Authorize Slack ↔️ Fable
6. Select the channel created in Step 1 for Fable to send notification to
7. Click save

That's it.

# How to test the integration

1. Create a demo
2. Add a lead form to the demo
3. Publish the demo
4. Open the published link in a tab
5. Fill up the lead form
6. You should see an alert in Slack within 2 mins.
